# Ehsan Cheraghi — portfolio

Live portfolio: https://ehsan-ch.github.io/

24 public project summaries in English, Persian and Danish, with six featured projects and 13 original saved reports. The collection includes interactive reports, browser-only demos and recorded simulations; each project states its limitations.

## Appearance
The header appearance button switches between black and light backgrounds. The choice is remembered locally across project pages. Persian uses right-to-left layout. Original research reports keep their own presentation.

## Hosting and updates
GitHub Pages publishes the root of the `main` branch. `.nojekyll` serves the files directly. No paid service, API, build dependency or backend is required. Edit the static files and commit to main to update the site.

For local preview: `python -m http.server 8785` and open http://localhost:8785/.

## Contents
- `index.html`, `app.js`, `content.js`: portfolio and translations
- `style.css`, `redesign.css`, `theme.css`, `theme.js`, `motion.js`: appearance and interaction
- `previews/`, `assets/`, `hand/`, `vendor/`: saved evidence and local demos
- `readmes/`, `credits/`, `attribution.html`: original documentation and license attribution

Project data and third-party assets retain their original licenses. See attribution.html and each linked source repository. No private account files, credentials or billing records are included.
